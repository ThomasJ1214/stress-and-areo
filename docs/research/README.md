# Feasibility research (pre-design)

These notes come from hands-on feasibility research done before the design spec was written.
Each topic file summarizes what an investigation agent **actually ran and verified** (marked VERIFIED)
versus what it recalled from literature (must be re-checked before use in code).

`prototypes/` holds throw-away research scripts and small output files that back the findings
(e.g. a prototype `.ork` parser validated against OpenRocket 24.12, a JPype driver for OpenRocket,
a Python port of OpenRocket's Barrowman calculator). They are **not** product code; the product
re-implements these properly with tests.

Note: some prototypes are ports of / drivers for OpenRocket (GPL-3.0). They are kept here only as
research references for this private/team project.
