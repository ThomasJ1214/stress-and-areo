# Stress & Aero

Desktop application (Windows) for aerodynamic, flight and structural/stress analysis of rockets,
built from OpenRocket `.ork` files, detailed CAD models (STEP/STL), or both.

> Status: **Milestone 1 (Foundation) in progress.** See the design spec in
> `docs/superpowers/specs/2026-10-05-rocket-analysis-app-design.md` and the plans in `docs/superpowers/plans/`.
